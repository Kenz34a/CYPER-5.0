CYPER Sans is a Latin/Vietnamese subset of Noto Sans, with width fixed at 100 and variable weights 400–700. The modified family is renamed CYPER Sans. Other scripts and emoji use the system fallback.

Source: https://github.com/google/fonts/tree/main/ofl/notosans
